# WB SDK

Python SDK для работы с [API Wildberries](https://dev.wildberries.ru/): товары, заказы, цены, склады, аналитика, реклама, финансы и другие разделы портала продавца.

## Быстрый старт

Установка и примеры использования описаны в README репозитория (раздел «Быстрый старт»).

## Документация

- [API Reference](api.md) — описание клиентов, исключений и модулей API.
- [Примеры кода](example.py) — примеры использования синхронного и асинхронного клиентов.

## Сборка документации локально

Установите dev-зависимости и запустите сервер документации:

```bash
pip install -e ".[dev]"
mkdocs serve
```

Откройте в браузере адрес, указанный в выводе (обычно http://127.0.0.1:8000).

Сборка статического сайта: `mkdocs build` (результат в каталоге `site/`).
