# Changelog

Все значимые изменения в проекте описываются в этом файле. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [1.2.6]

### Добавлено

- Асинхронное ожидание результата в методе получения тарифов, улучшена обработка возвращаемых данных
- Импорт модуля `inspect` для проверки корутин

---

## [1.2.5]

### Добавлено

- Метод `delete_order_meta` для удаления метаданных заказа по ключу в ClickCollect API
- Тесты для метода `delete_order_meta` (с ключом и без)

### Изменено

- Описание песочницы в README: соответствия разделов и URL
- Новые базовые URL в конфигурации API: разделы `dp_calendar`, `supplies`, `statistics`
- Описание Python SDK для API Wildberries: новые модули и методы (пользователи, тарифы, отчёты, реклама, финансы), расширены возможности клиента

---

## [1.2.4]

### Добавлено

- Обвязка новых API в клиентах (доступ к новым разделам)
- API для работы с цифровыми товарами WBD: ключи, офферы, контент; тесты
- API для работы с финансами и документами: баланс, категории документов, список и загрузка документов; тесты

### Изменено

- Права на выполнение скрипта `release.sh` (сделаны исполняемыми)

---

## [1.2.3]

### Добавлено

- API тарифов: комиссии, тарифы на коробки, паллеты, возвраты, коэффициенты приёмки; Pydantic-схемы и тесты
- API поставок FBW: коэффициенты приёмки, опции приёмки, список складов, транзитные тарифы, детали поставок; тесты
- API заказов самовывоза (Click&Collect): новые заказы, подтверждение, подготовка, статусы, метаданные; Pydantic-схемы и тесты
- API заказов DBS: новые заказы, информация о заказах, статусы, отмена, метаданные; Pydantic-схемы и тесты
